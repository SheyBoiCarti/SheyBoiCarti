### 🚀 Technical Focus

- 🧠 **AI & Machine Learning:** Architecting end-to-end Retrieval-Augmented Generation (RAG) pipelines, semantic vector search, LLM integrations (Llama 3.3, NVIDIA AI), conversational memory, and deep learning vision systems.
- ⚙️ **Backend & Distributed Systems:** Building asynchronous RESTful & GraphQL APIs with FastAPI, .NET Core, and Node.js with per-session state, SSE streaming, and concurrency controls.
- 💻 **Full-Stack & Mobile Development:** Creating modern, responsive applications using Next.js, React, React Native, and Tailwind CSS.
- 🎮 **Systems & Interactive Tech:** Low-level development in C++, game subsystems, and interactive spatial applications in Unreal Engine 5 and Unity.
